# SkyCooker RMC-M92S — діагностика по Bluetooth

Сторінка для Chrome на Android: підключається до мультиварки REDMOND SkyCooker RMC-M92S
протоколом Ready for Sky (R4S), спарюється власним ключем, читає статус і показує всі байти обміну.

## Як викласти на GitHub Pages (≈5 хв)

1. На github.com натисніть **New repository** → назва `skycooker` → **Public** → **Create repository**.
2. На сторінці репозиторію: **Add file → Upload files** → перетягніть `index.html` (і цей `README.md`) → **Commit changes**.
3. **Settings → Pages** → *Source*: **Deploy from a branch** → *Branch*: `main`, папка `/ (root)` → **Save**.
4. Через 1–2 хвилини сторінка буде за адресою `https://<ваш-логін>.github.io/skycooker/`.

## Як тестувати

1. На телефоні увімкніть Bluetooth і геолокацію. Закрийте офіційний застосунок Redmond.
2. Відкрийте адресу в **Chrome**, дозвольте доступ до пристроїв поблизу.
3. **Знайти мультиварку** → оберіть її у списку (якщо немає — галочка «всі пристрої»).
4. **Спарювання (30 с)** → одразу затисніть кнопку спарювання на мультиварці.
5. **Статус**, потім вмикайте «Опитувати кожні 2 с» і перемикайте програми на панелі мультиварки.
6. Для кожної програми — **Знімок** з назвою програми.
7. Натисніть **Скопіювати журнал** і **Скопіювати знімки** та надішліть результат.
